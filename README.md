# ponto-de-entrega-voluntaria
Mapa interativo dos pontos de entrega voluntária de resíduos em Itanhaém (SP). Filtre por material e bairro, veja no mapa onde descartar pilhas, lâmpadas, remédios, óleo e eletrônicos, e trace a rota até o local. Feito com acessibilidade: letra ajustável, alto contraste e leitura em voz alta.
